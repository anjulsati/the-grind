# CU Prep OS

**Live site: https://anjulsati.github.io/cu-prep-os/**

A day-by-day plan for a Chandigarh University CSE student going from zero to placement-ready in **5 months**, with a parallel **agentic AI dev track** and small momentum tasks during endsems.

---

## For the reviewer

Open the site → **Review** tab. Pick a verdict on each line, comment on any week you disagree with, then hit **Download review .md** and send the file back. Nothing leaves the browser until you download.

---

## Structure

```
Nov 16 – Dec  7   Momentum mode    22 days × 40 min   (during endsems)
Dec  8 – Apr 26   The 5 months     140 days           (DSA + CS + AI track)
May    – Jul      Phase 3          DP depth, mocks, 10 apps/week
Aug    – Dec 2027 Placement season
```

590 checkboxes. Progress saves in the browser only.

---

## The three tracks, in parallel

1. **DSA** — 12 problems/week, Java, ~210 total, every 7th day is revision.
2. **CS** — 30 min/day: DBMS+SQL, OS, CN, OOP+Java, LLD+HLD, AI fundamentals.
3. **AI dev** — 3 × 45 min/week: Python → LLM APIs → RAG → agents → evals → guardrails → deploy. Two live projects by week 17.

Plus applications from week 8 and mocks in week 19.

## Rules

1. One sheet, one language, one stack.
2. 45 min alone → 20 min learning → rewrite from scratch.
3. After week 6, revision beats new problems.
4. Deploy in week 12, not week 20.
5. A collapsed day = one easy problem. Never zero.
6. CGPA floor 7.5, zero backlogs. You have 7.65 — don't waste it.
7. Don't buy a course.
