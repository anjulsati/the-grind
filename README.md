# CU Prep OS

A day-by-day plan for a Chandigarh University CSE student (Java track, CGPA 7.65) going from zero to placement-ready in **5 months**, with a **parallel dev track** and **small momentum tasks during endsems**.

**No build step. No dependencies. No server required.**

---

## Open it

Double-click `index.html`. That's it.

If your browser blocks local files:

```bash
cd cu-prep-os
python3 -m http.server 8899
# visit http://localhost:8899
```

---

## The structure

```
Nov 16 – Dec  7   Momentum mode    22 days × 35 min  (while you write endsems)
Dec  8 – Apr 26   The 5 months     140 days          (the real work)
May    – Jul      Phase 3          DP depth, mocks, 10 apps/week
Aug    – Dec 2027 Placement season
```

590 checkboxes. Progress saves in your browser only.

## The three tracks run in parallel

1. **DSA** — 12 problems/week, ~210 total, revision built in every 7th day.
2. **CS** — 30 min/day, one area per 2–3 weeks, revised twice before the end.
3. **Dev** — 3 × 45 min/week: Git → Java/Spring Boot → deploy → tests → Docker → LLD. Two deployed projects by week 17.

Plus applications from week 8 and mocks from week 19.

---

## Rules that matter more than the schedule

1. One sheet, one language, one stack. Switching is the #1 killer.
2. 45 min alone → 20 min learning → rewrite from scratch.
3. After week 6, revision beats new problems.
4. Deploy in week 12, not week 20.
5. A collapsed day = one easy problem. Never zero.
6. CGPA floor 7.5, zero backlogs. You have 7.65 — don't waste it.
7. Don't buy a course.
